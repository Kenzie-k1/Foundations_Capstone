# Foundations Cohort 15 Capstone Project
My Capstone project is a simple application that allows employees and supervisors to edit personal employee information such as names, phone numbers and emails.
This program's main objective is to help keep track of skill sets that included employees have mastered or still need work on through assessment scores.
Employee based users have the basic abilities of viewing their own scores from assessments for each skill set as well as viewing their own personal information and making edits to that basic profile.
Supervisor based users are able to view a list of employees, assessments, skill sets, or results as well as searching for specific items.
Results can be imported from a CSV file, or exported to one.
Users, skill sets, assessments and results can all be added or edited by supervisors.

## What to expect as a Manager.
After successfully logging in you will be redirected to a specialized menu for this user type. These options will redirect you to the associated actions.
* Select menu choices by entering the capital key to the left of the menu option below.
    1. Search for records in the database.
        * This will open a sub menu where you can search for specific data sets, such as certain employees, skills, and results.
          If you don't know the associated ID's you can select the third option to view all which will include ID's.
    2. Adding to the database.
         * This will open a sub menu to redirect you to add information based on which fields you need to add to, such as a new skill set or employee.
    3. View database.
        * This will have you select what information sets you want pulled up and displayed. This includes names, IDs and any other associated data.
    4. Edit database.
        * Similar to adding, however this will allow you to edit existing entries, this will not update ID's or created dates.
    5. Import results
         * Import results from an existing CSV file into your database.
    6. Export Competency Results
         * Export result sets by competencies to a CSV file. This will be a single competency displayed with all associated testing results.
    7. Export Employee Results.
         * Export result sets by an employee to a CSV file. This will be a single employee displayed with all testing results from this person.
    8. Quitting from this menu will log you out.
 
## What to expect as an Employee.
